# First Steps

Start with [Getting Started](getting-started.md): run a complete order transformation
in your browser, change one quantity, and check the new output. That guide is the
introductory learning path.

Use `input` for the incoming payload, for example `input.id` or
`input.shipping.city`. Create bindings with `LET name = expression` and construct
the result with `OUTPUT { ... }`.

After your first result, continue with the [Tour of Branchline](../learn/index.md)
or [install the JVM or Node CLI](install.md) to run your saved files locally.
